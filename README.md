# Lovit для Home Assistant

Кастомная интеграция Home Assistant, которая показывает **баланс лицевого счёта** интернет-провайдера
[Lovit](https://lk.lovit.ru) и следит за состоянием подписки: абонентская плата, дни до отключения,
данные подключений.

Интеграция работает с тем же API, что и веб-личный кабинет `lk.lovit.ru/api/user/info`, поэтому
отдельный токен или настройки в кабинете не нужны — достаточно логина и пароля.

## Возможности

- Сенсор баланса (`sensor.*_balance`) в рублях с device class `monetary` — его можно вывести
  на Lovelace и использовать в автоматизациях, в том числе «низкий баланс».
- Сенсор абонентской платы (`payment`) и сенсор «дней до отключения» (`days_to_off`).
- В атрибутах баланса — `payment`, `days_to_off`, `ip` и список подключений (`subscriptions`)
  с тарифом, типом и датой старта.
- Автоматическая повторная авторизация при истечении сессии.
- Поток повторной авторизации (reauth), если пароль в кабинете сменили.
- Настраиваемый интервал опроса (5–1440 минут, по умолчанию 15).
- Поддержка нескольких аккаунтов Lovit одновременно.

## Установка

### HACS (рекомендуется)

1. HACS → «Интеграции» → меню (⋮) → «Пользовательские репозитории».
2. Добавьте URL этого репозитория, категория — **Integration**.
3. Найдите «Lovit» в HACS и установите.
4. Перезапустите Home Assistant.

### Вручную

Скопируйте папку `custom_components/lovit` в `<config>/custom_components/lovit` (в итоге должен
получиться путь `<config>/custom_components/lovit/manifest.json`) и перезапустите Home Assistant.

```
<config>/
└── custom_components/
    └── lovit/
        ├── __init__.py
        ├── config_flow.py
        ├── const.py
        ├── coordinator.py
        ├── diagnostics.py
        ├── entity.py
        ├── lovit_api.py
        ├── manifest.json
        ├── schema.py
        ├── sensor.py
        ├── strings.json
        └── translations/
            ├── en.json
            └── ru.json
```

## Совместимость

- Home Assistant **2025.1** и новее; API актуальной ветки 2026.10 (probatio) учтён.
- В HA 2026.10 схемы форм переехали с `voluptuous` на `probatio`; модуль
  `schema.py` автоматически выбирает доступный вариант, поэтому интеграция
  работает и на старых, и на новых версиях.
- Python 3.12+ (требование Home Assistant).

## Настройка

1. **Настройки → Устройства и службы → Добавить интеграцию → Lovit**.
2. Введите:
   - **Логин** — номер договора или номер телефона, как на странице входа `lk.lovit.ru/login`;
   - **Пароль** — пароль от личного кабинета.
3. Нажмите «Отправить». Интеграция выполнит реальный вход в кабинет и, если он удался, создаст
   устройство `Lovit <номер>` с сенсорами.

Пароль хранится в `.storage/core.config_entries` в открытом виде — как и у большинства
интеграций, работающих по логину/паролю. Не публикуйте папку `.storage`.

## Сенсоры

| Сущность | Описание | Единица |
| --- | --- | --- |
| `sensor.lovit_<account>_balance` | Текущий баланс лицевого счёта | ₽ |
| `sensor.lovit_<account>_payment` | Абонентская плата | ₽ |
| `sensor.lovit_<account>_days_to_off` | Дней до отключения (значение API `days_to_off`) | д |

Атрибуты сенсора баланса:

```yaml
payment: 1100
days_to_off: 0
ip: 95.x.x.97
subscriptions:
  - sub_id: ""
    mobile_no: ":c9:bf:ed"
    status: "0"
    desk: XL
    type: DHCP
    tariff_id: 162
    sub_tarif_started: "2025-02-25 23:50:00"
    mod_serv: 1
```

> Значение `days_to_off` отдаётся провайдером как есть. У активных договоров с положительным
> балансом оно часто равно `0` — это нормально и не означает скорое отключение.

## Опции

**Настройки интеграции → Настроить**: интервал обновления в минутах (5–1440, по умолчанию 15).
Сессия личного кабинета «скользящая» и продлевается при каждом запросе, поэтому частый опрос
не создаёт лишних авторизаций. Слишком маленький интервал не нужен — баланс меняется редко,
а на API действует ограничение примерно 150 запросов в минуту.

## Примеры использования

### Уведомление о низком балансе

```yaml
automation:
  - alias: "Lovit: низкий баланс"
    trigger:
      - platform: numeric_state
        entity_id: sensor.lovit_1281217_balance
        below: 300
        for: "02:00:00"
    action:
      - service: notify.mobile_app_phone
        data:
          title: "Lovit: баланс на исходе"
          message: >
            Баланс {{ states('sensor.lovit_1281217_balance') }} ₽,
            абонентская плата {{ state_attr('sensor.lovit_1281217_balance', 'payment') }} ₽.
```

### Датчик на панель

```yaml
type: entities
title: Интернет Lovit
entities:
  - entity: sensor.lovit_1281217_balance
    name: Баланс
  - entity: sensor.lovit_1281217_payment
    name: Абонплата
  - entity: sensor.lovit_1281217_days_to_off
    name: Дней до отключения
```

## Как это работает

`lk.lovit.ru` — приложение на Laravel с обычной сессионной аутентификацией. Интеграция
повторяет путь браузера:

1. `GET https://lk.lovit.ru/login` — забирается скрытое поле `_token` (CSRF) и cookie сессии;
2. `POST https://lk.lovit.ru/login` с полями `_token`, `login`, `password` — Laravel отвечает
   редиректом и устанавливает аутентифицированную cookie;
3. `GET https://lk.lovit.ru/api/user/info` с этой cookie — возвращает JSON с балансом.

Cookie хранятся только в памяти Home Assistant и создаются заново при каждом старте. Если сессия
истекла, интеграция входит повторно; если провайдер отклоняет пароль — запускается поток
повторной авторизации с уведомлением в интерфейсе.

## Отладка

Включите подробный лог:

```yaml
logger:
  default: warning
  logs:
    custom_components.lovit: debug
```

Диагностику можно скачать в интерфейсе: **Настройки → Устройства и службы → Lovit →
⋮ → Скачать диагностику**. Пароль в неё не попадает.

Типичные проблемы:

| Симптом | Причина и решение |
| --- | --- |
| `invalid_auth` при настройке | Неверный логин/пароль, либо вход в кабинет требует подтверждения по SMS. Проверьте вход на `lk.lovit.ru` в браузере. |
| `cannot_connect` | Нет доступа к `lk.lovit.ru` из контейнера/хоста Home Assistant (DNS, файрвол, блокировка по геолокации). |
| Сенсоры `unknown` после обновления | API изменил формат ответа — включите debug-лог и создайте issue с фрагментом ответа. |
| Сущности не появились | Проверьте, что папка называется именно `lovit`, и перезапустите Home Assistant. |

## Ограничения и дисклеймер

- API личного кабинета **неофициальный** и может измениться в любой момент; интеграция
  не связана с Lovit.
- Вход по коду из SMS / двухфакторная аутентификация не поддерживаются.
- Интеграция только читает данные: платежи, смена тарифа и прочие действия не выполняются.
- Данные учётной записи хранятся в конфигурации Home Assistant; используйте бэкапы осознанно.
